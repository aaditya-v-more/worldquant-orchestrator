# Expression notes

Use ordinary decimals, not scientific notation. Backfill sparse fundamentals
with `ts_backfill(field, 60)`. Check available operators before spending a
simulation. Group identifiers include subindustry, industry, sector and market.
`adv20` is a pv1 field; confirm dataset/region/universe compatibility.

For vector fields, use the appropriate available vector aggregation operator.
Match region, universe and delay between field discovery and simulation.
Compare backtests using the same settings and test period. Grades do not establish
submission eligibility; inspect failing, missing and pending checks in the gate.
